### 1. gpu unlock
via:     

```
$ cat bench_tensor.py
import torch
import time

# 确保 CUDA 可用
device = torch.device("cuda")
print(f"Using GPU: {torch.cuda.get_device_name(0)}")

# 创造大规模 BF16 矩阵 (例如 8192 x 8192)
# 这会强制压榨 Tensor Core 的矩阵运算能力
size = 8192
a = torch.randn((size, size), dtype=torch.bfloat16, device=device)
b = torch.randn((size, size), dtype=torch.bfloat16, device=device)

# 预热
for _ in range(10):
    _ = torch.matmul(a, b)
torch.cuda.synchronize()

# 正式计时
torch.cuda.synchronize()
start = time.time()
iterations = 50
for _ in range(iterations):
    c = torch.matmul(a, b)
torch.cuda.synchronize()
end = time.time()

elapsed = end - start
# 计算 TFLOPS: 2 * N^3 * iterations / time
flops = 2 * (size ** 3) * iterations
tflops = (flops / elapsed) / 1e12

print(f"Time elapsed: {elapsed:.4f} seconds")
print(f"Performance: {tflops:.2f} TFLOPS (BF16)")
```

### 3. pacman issue
issue:      

```
error: failed to commit transaction (conflicting files)
boost-libs: /usr/lib/libboost_locale.so.1.92.0 exists in filesystem
```
Examine the ownership:     

```
pacman -Qo /usr/lib/libboost_locale.so.1.92.0
error: No package owns /usr/lib/libboost_locale.so.1.92.0，
```
Directly overwrite:     

```
sudo pacman -Syu --overwrite '/usr/lib/libboost*.so*'
```
