# 20261020
### 1. pi(drawing)
Install d2:     

```
curl -fsSL https://d2lang.com/install.sh | sh -s --
```
Install some plugins:    

```
1. diagram-design（强烈推荐）

专为 Claude Code、Codex、Pi 等 Agent 设计，支持 40+ 种专业图表（架构图、流程图、时序图、数据模型、泳道图等）。
输出是自包含的 HTML + SVG，设计感强、可直接交付，不走普通 Mermaid 的“廉价感”。

pi install https://github.com/cathrynlavery/diagram-design

2. pi-drawio

专门生成原生 .drawio 文件（可继续在 draw.io 里编辑），并支持导出 PNG/SVG/PDF。
安装：pi install npm:pi-drawio，然后 /reload

3. @mcuste/pi-diagram

用 D2 语言生成架构/流程图，token 效率较高。
安装：pi install npm:@mcuste/pi-diagram（需要本机有 D2 CLI）。
```
