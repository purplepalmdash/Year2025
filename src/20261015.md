### 3. nvm(ubuntu2204)
Install and configure nvm:    

```
curl -fsSL https://gitee.com/mirrors/nvm/raw/v0.40.1/install.sh | bash
source ~/.bashrc
nvm --version
# 输出版本号（如 0.40.1）即表示安装成功
export NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node
export NVM_NPM_MIRROR=https://npmmirror.com/mirrors/npm

echo 'export NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node' >> ~/.bashrc
echo 'export NVM_NPM_MIRROR=https://npmmirror.com/mirrors/npm' >> ~/.bashrc
source ~/.bashrc

nvm install 22.23.3
nvm alias default 22.23.3
nvm use 22.23.3

npm config set registry https://registry.npmmirror.com

node -v          # 应显示 v22.23.3
npm -v           # 显示对应的 npm 版本
npm config get registry  # 应显示 https://registry.npmmirror.com/

```

### 5. wine(32-bit) issue
Issue:     

```
test@codefree:~$ winetricks -q mfc42 vcrun6

/home/test/.wine/system.reg:#arch=win64

warning: wine cmd.exe /c echo '%AppData%' returned empty string, error message ""
```
