### 1. fedora 42 worktips
Download the iso from nju:    

```
axel https://mirrors.nju.edu.cn/fedora-archive/fedora/linux/releases/42/Server/x86_64/iso/Fedora-Server-dvd-x86_64-42-1.1.iso
axel https://mirrors.nju.edu.cn/fedora-archive/fedora/linux/releases/42/KDE/x86_64/iso/Fedora-KDE-Desktop-Live-42-1.1.x86_64.iso
```


```
sudo dnf install dnf-plugins-core   # 如果还没有的话
sudo dnf copr enable lepp739/virtio-gpu-virgl-vid-accel

sudo sed -i '/^\[fedora\]/,/^\[/ s/^enabled=.*/&\nexclude=qemu*/' /etc/yum.repos.d/fedora.repo
sudo sed -i '/^\[updates\]/,/^\[/ s/^enabled=.*/&\nexclude=qemu*/' /etc/yum.repos.d/fedora-updates.repo

sudo dnf install 'qemu*'

# Install Mesa VA
# 如果还没启用 RPM Fusion
sudo dnf install https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
sudo dnf install https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

# 主机和客户机都装
sudo dnf install mesa-va-drivers-freeworld

```
