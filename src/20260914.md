### 1. redsocks issue
After running redroid, redsocks will fail :     

```
$ sudo ./redsocks.sh start
1789432952.110632 err redsocks.c:1390 redsocks_init_instance(...) bind: Address already in use
Warning: Extension REDIRECT revision 0 not supported, missing kernel module?
iptables v1.8.10 (nf_tables): RULE_APPEND failed (No such file or directory): rule in chain OUTPUT
Warning: Extension REDIRECT revision 0 not supported, missing kernel module?
iptables v1.8.10 (nf_tables): RULE_APPEND failed (No such file or directory): rule in chain OUTPUT
```
Solved via:      

```
sudo modprobe xt_REDIRECT
sudo modprobe nf_nat
sudo modprobe iptable_nat
```
