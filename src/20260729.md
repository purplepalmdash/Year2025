### 1. video devices(/dev/video)
Detected via v4l2-ctl:     

```
$ v4l2-ctl --list-devices
USB Video: USB Video (usb-0000:00:14.0-4):
	/dev/video0
	/dev/video1
	/dev/media0
```
video0 for capture, video1 for metadata.     

```
v4l2-ctl -d /dev/video0 --all | head -n 15
v4l2-ctl -d /dev/video1 --all | head -n 15
media-ctl -d /dev/media0 -p
```
### 2. rm git commit history
Steps as following:      

```
# 1. 创建并切换到一个没有任何历史记录的“孤立”分支（假设命名为 temp-main）
git checkout --orphan temp-main

# 2. 将当前目录下的所有文件暂存
git add -A

# 3. 提交这些文件，这会成为你的“初始提交”
git commit -m "Initial commit"

# 4. 删除你本地原有的主分支（假设是 main，如果是 master 请替换为 master）
git branch -D main

# 5. 将当前分支重命名为 main
git branch -m main

# 强制推送更新远程 main 分支
git push -f origin main
```
