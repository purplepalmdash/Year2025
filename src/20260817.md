### vim .repo/local_manifests/01-removes.xml

$ repo sync -l -j$(nproc) --force-sync
... A new version of repo (2.65) is available.

    cp /media/nvme/dragon_waydroid/.repo/repo/repo /usr/local/bin/repo
error: in sync -l -j20 --force-sync: duplicate path external/v4l2_codec2 in /media/nvme/dragon_waydroid/.repo/manifest.xm

### 默认 manifest 里已经有这个 path：
### <!-- .repo/manifests/default.xml -->
### <project path="external/v4l2_codec2" name="LineageOS/android_external_v4l2_codec2" groups="pdk" />
### 
### dragon 的 02-waydroid.xml 又加了同 path：
### <project path="external/v4l2_codec2" name="dragon-waydroid/android_external_v4l2_codec2" ... />
### 
### 于是报 duplicate path。之前删掉的 remove 写的是错误名字：
### <!-- 错误：默认里根本没有这个 name -->
### <remove-project name="platform/external/v4l2_codec2" />
### 
### 真正要用的 name 是 LineageOS/android_external_v4l2_codec2。

$ vim .repo/local_manifests/01-removes.xml
加上这一行（不要用 platform/...）：
  <remove-project name="LineageOS/android_external_v4l2_codec2" />
```

```

### 2. x13s networking(usb networking)
Enable following items. then rebuild the kernel, reboot.   

```
CONFIG_NETDEVICES=y
CONFIG_USB=y
CONFIG_USB_NET_DRIVERS=y
CONFIG_USB_USBNET=y
CONFIG_MII=y
CONFIG_USB_NET_AX8817X=y
```
