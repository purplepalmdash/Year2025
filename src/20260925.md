### 1. nvidia t4(qwen38-27b)
Step:    

```
cd ~/Code/
    git clone https://github.com/PrismML-Eng/Bonsai-demo.git
cd ~/Code/Bonsai-demo
export BONSAI_FAMILY=bonsai2   # bonsai2 (default), ternary (1.58-bit), or bonsai (1-bit)
    export BONSAI_MODEL=27B        # 27B (default), 8B, 4B, or 1.7B — earlier families only
./setup.sh
 pip install nvidia-cuda-runtime-cu12 --break-system-packages --user -i https://pypi.tuna.tsinghua.edu.cn/simple
pip install nvidia-cublas-cu12 --break-system-packages --user -i https://pypi.tuna.tsinghua.edu.cn/simple
PY_VER=$(python3 -c "import sys; print(f'{sys.version_info.major}.{sys.version_info.minor}')")
export LD_LIBRARY_PATH=$HOME/.local/lib/python${PY_VER}/site-packages/nvidia/cuda_runtime/lib:$HOME/.local/lib/python${PY_VER}/site-packages/nvidia/cublas/lib:$LD_LIBRARY_PATH
./scripts/start_llama_server.sh
```
Or you could write a startup.sh:     

```
$ cat startup.sh
PY_VER=$(python3 -c "import sys; print(f'{sys.version_info.major}.{sys.version_info.minor}')")
export LD_LIBRARY_PATH=$HOME/.local/lib/python${PY_VER}/site-packages/nvidia/cuda_runtime/lib:$HOME/.local/lib/python${PY_VER}/site-packages/nvidia/cublas/lib:$LD_LIBRARY_PATH
./scripts/start_llama_server.sh
```
For saving the vmem, disable the nx server's hardware accel.
