# 20260909
### 1. qwen35-4b for compact
Create modelfile:    

```
$ cat modelfile-qwen354b
FROM qwen3.5:4b

PARAMETER num_ctx 131072
PARAMETER temperature 0.6
PARAMETER top_p 0.9
```
Create new model and run:    

```
ollama create qwen354b-256k -f modelfile-qwen354b 
ollama run qwen354b-256k
```
make it permanent:      

```
curl http://localhost:11434/api/generate -d '{
  "model": "qwen354b-256k",
  "keep_alive": -1
}'
```
Reverse tunnel:      

```
 ssh -p 16522 -R 8021:127.0.0.1:11434 test@kkk.kkk.kkk.com
```
