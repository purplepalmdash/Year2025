### 1. ip show stats
Via:    

```
ip -s link                  # 看所有接口
ip -s link show eth0        # 只看某个接口
cat /proc/net/dev           # 最底层的原始数据
```
### 2. Add/remove default gw
Add default route:    

```
sudo ip route add default via 192.168.1.33 dev eth0
 
```
delete default route:    

```
sudo ip route del default via 192.168.1.33 dev eth0
```
