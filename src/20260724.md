### 2. waydroid network issue
Solved via:     

```
$ sudo waydroid shell
Under shell, do following:    
# 1. 在 main 表添加默认网关
ip route add default via 192.168.240.1 dev eth0 table main

# 2. 删除那条 32000: from all unreachable 的拦截规则
ip rule del preference 32000

# 3. 添加一条最通用的策略：无条件查找 main 表
ip rule add from all lookup main pref 30000
```
### 3. purge waydroid setup
via:     

```
waydroid session stop
sudo waydroid container stop

# （可选）如果有挂载残留，重置 Waydroid 状态
sudo waydroid session stop


# 2. 手动删除残余的系统数据（防漏）
sudo rm -rf /var/lib/waydroid
sudo rm -rf /usr/share/waydroid-extra

# 3. 清空当前用户的配置和 Android 存储数据
rm -rf ~/.local/share/waydroid
rm -rf ~/.share/waydroid
rm -rf ~/.local/share/applications/waydroid*
rm -rf ~/.local/share/applications/app_waydroid*
```
Re-copy the image to folder, then `sudo waydroid init -f` again.
