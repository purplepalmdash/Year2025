### 1. ollama for vision
Create 16K context ollama model:     

```
cat > Modelfile << EOF
FROM qwen354b-256k:latest
PARAMETER num_ctx 16384
# 可选：再加一些有利于压缩和视觉的参数
PARAMETER temperature 0.3
PARAMETER top_p 0.9
EOF

ollama create qwen-compress-vision -f Modelfile
```
Edit ollama service via:     

```
$ sudo systemctl edit ollama.service
[Service]
Environment="OLLAMA_KEEP_ALIVE=-1"
```
Reload and restart:     

```
sudo systemctl daemon-reload
sudo systemctl restart ollama
```
Auto set parameter for specified model:      

```
root@ai:/home/dash# sudo chmod +x /usr/local/bin/preload-ollama.sh
root@ai:/home/dash# cat /usr/local/bin/preload-ollama.sh
#!/bin/bash
# 等待 Ollama 服务完全就绪
until curl -s http://localhost:11434/api/tags > /dev/null; do
        sleep 2
    done
# 发送空请求触发加载，并指定 keep_alive 参数为永久 (-1)
curl http://localhost:11434/api/generate -d '{
  "model": "qwen-compress-vision",
    "keep_alive": -1
}'
curl http://localhost:11434/api/generate -d '{ "model": "qwen-compress-vision","think":false}'
```
Edit a new system service:      

```
# vim /etc/systemd/system/ollama-preload.service

[Unit]
Description=Preload Ollama Model on Boot
After=ollama.service
Requires=ollama.service

[Service]
Type=oneshot
ExecStart=/usr/local/bin/preload-ollama.sh

[Install]
WantedBy=multi-user.target
```
Reload and start the service:    

```
sudo systemctl daemon-reload
sudo systemctl enable --now ollama-preload.service
```
Now you got a 100% GPU ollama running instance:      

```
# ollama ps
NAME                           ID              SIZE      PROCESSOR    CONTEXT    UNTIL   
qwen-compress-vision:latest    efe5f844d245    3.6 GB    100% GPU     16384      Foreve
```
