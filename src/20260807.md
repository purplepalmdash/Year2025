### 2. manjaro kernel
list and install kernel via:    

```
mhwd-kernel -l
输出会列出当前 Manjaro 软件库中所有支持的内核版本（例如 linux612、linux613 等）。

2. 安装最新的稳定版内核
找到列表中版本号最新的内核包名（假设当前最新版为 linux72），运行：

sudo mhwd-kernel -i linux72
```
