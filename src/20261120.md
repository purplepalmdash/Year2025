### 1. lxc based environment
安装 LXD：

```
sudo snap install lxd
```

将你的用户加入 lxd 组（这样以后敲 lxc 命令不用每次都加 sudo）：

```
sudo usermod -aG lxd $USER
newgrp lxd
```
最小化初始化:    

```
lxd init --minimal
```

创建并启动一个名为 ubuntu-193 的容器（这里用容器，启动快、资源占用少；如果你需要完全隔离的虚拟机，可以在命令末尾加 --vm，但需要 CPU 支持虚拟化）：   

```
lxc launch ubuntu:24.04 ubuntu-193
```
默认的网络情况:     

```
+------------+---------+----------------------+-----------------------------------------------+-----------+-----------+
|    NAME    |  STATE  |         IPV4         |                     IPV6                      |   TYPE    | SNAPSHOTS |
+------------+---------+----------------------+-----------------------------------------------+-----------+-----------+
| ubuntu-193 | RUNNING | 10.188.153.25 (eth0) | fd42:d366:2059:9d66:216:3eff:fe8b:6a3e (eth0) | CONTAINER | 0         |
+------------+---------+----------------------+-----------------------------------------------+-----------+-----------+

```
屏蔽继承的 eth0:    

```
$ lxc config device add ubuntu-193 eth0 none
Device eth0 added to ubuntu-193
```
添加桥接到 br0 的新网卡

```
$ lxc config device add ubuntu-193 eth1 nic nictype=bridged parent=br0 name=eth0
Device eth1 added to ubuntu-193

```
此时:    

```
$ lxc ls
+------------+---------+---------------------+------+-----------+-----------+
|    NAME    |  STATE  |        IPV4         | IPV6 |   TYPE    | SNAPSHOTS |
+------------+---------+---------------------+------+-----------+-----------+
| ubuntu-193 | RUNNING | 192.168.1.77 (eth0) |      | CONTAINER | 0         |
+------------+---------+---------------------+------+-----------+-----------+
```
进入到容器里并配置固定IP地址:      

```
dash@ai:~$ lxc shell ubuntu-193
root@ubuntu-193:~# cat > /etc/netplan/50-cloud-init.yaml <<EOF
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: no
      addresses:
        - 192.168.1.193/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses: [223.5.5.5,180.76.76.76]
EOF
root@ubuntu-193:~# netplan apply 
root@ubuntu-193:~# touch /etc/cloud/cloud-init.disabled
```
