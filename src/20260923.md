### 1. ninfer
`https://github.com/geoffwatts/ninfer-v100`, 从零编写的 C++/CUDA 高性能单 GPU 推理引擎，专门针对 NVIDIA Tesla V100（Volta, sm_70） 优化.   

软件实现的 NVFP4（Volta 上通过定制 FP16 Tensor Core / SIMT 内核模拟）和投机解码（MTP / DFlash2），可达到很高的解码速度

```
NInfer 是什么样的概念？NInfer 是一个从零写起的高性能单 GPU 推理引擎（C++ + CUDA 编写）。它的核心特点是：极度专精：不是“什么模型都能跑”的通用工具，而是专门针对特定几个 Qwen 系列模型（如 Qwen3.6-27B、Qwen3.8-27B、Qwen3.6-35B-A3B）深度优化。
单卡极致性能：设计目标就是在一张 GPU 上跑得尽可能快。支持 1～8 个并发请求，模型一直常驻显存。
多模态：不仅能处理文字，还能处理图片和视频输入。
接口友好：既有命令行工具（CLI），也提供兼容 OpenAI 和 Anthropic 的 HTTP API，方便当本地服务器用。
定制权重格式：模型不是普通的 Hugging Face 格式，而是打包成特殊的 .ninfer 文件（里面包含权重、分词器、聊天模板等一切需要的东西）。

可以把它想象成：一辆专门为某几条赛道调教的赛车，而不是普通家用轿车。它牺牲了“通用性”，换来在特定硬件和模型上极高的速度。
在你之前问的那个项目里，ninfer-v100 就是 NInfer 针对老旧但便宜的 Tesla V100 显卡做的移植版本。
```

```
NVFP4 的具体特点（用大白话讲）每个数字只用 4 个比特 来表示（比 FP16 少了 4 倍）。
它不是简单的整数，而是一种特殊的浮点数格式（E2M1：1 位符号 + 2 位指数 + 1 位尾数），能表示大概 -6 到 +6 之间的一些值。
为了尽量保持精度，它采用了分块缩放（microscaling）：每 16 个数字共享一个较高精度的缩放因子（用 FP8 表示）
整个张量还有一个全局缩放因子

在 NVIDIA 最新的 Blackwell 架构显卡上，有专门的硬件加速，速度可以非常快，显存占用大约只有 FP16 的 1/3.5 左右，而且精度损失通常很小（大模型上往往 <1%）。

在 NInfer-v100 里的特殊之处V100 是 2017 年的老架构（Volta），没有原生支持 NVFP4 的硬件。
所以 NInfer 在 V100 上用软件方式模拟实现了 NVFP4：通过精心编写的 FP16 Tensor Core 和普通计算内核，把 NVFP4 权重解压并计算。这样老卡也能享受到 4-bit 带来的显存节省和部分加速。

NInfer = 一个专为速度而生的“本地 AI 模型运行器”（特别擅长在一张卡上把 Qwen 模型跑得飞快）。
NVFP4 = 一种非常省显存、能加速的“模型减肥格式”（4 比特精度），NInfer 支持它，甚至能在不支持硬件的老卡上用软件实现。
```
