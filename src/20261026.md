### 1. i915 vfio/vfs issue
Solved via:    

```
grubby --update-kernel=ALL --remove-args="i915.reset=0"
grubby --update-kernel=ALL --remove-args="i915.guc_log_size_debug=16"
grubby --update-kernel=ALL --remove-args="i915.force_probe=*"    
```
Then check the `/etc/default/grub`, remove these 3 items, then:     

```
grub2-mkconfig -o /boot/efi/EFI/rocky/grub.cfg
reboot
```
Then vfs will be OK .
