原因，选错了分支： `git clone --branch virtio-media --depth=2 https://github.com/Gnurou/linux`,     

Should be:      

`git clone --branch b4/virtio-media --depth=2 https://github.com/Gnurou/linux`

Clone the right branch:    

```
git -c http.proxy=socks5h://192.168.1.208:1080 clone --branch b4/virtio-media --depth=2 https://github.com/Gnurou/linux
cd linux/
cp arch/x86/configs/virtio_media_defconfig arch/arm64/configs/
make O=build_virtio_media  virtio_media_defconfig
make O=build_virtio_media  menuconfig
make O=build_virtio_media -j$(nproc) Image
```
Open following configurations:    

```
CONFIG_VIRTIO_MMIO
CONFIG_PCI_HOST_GENERIC
CONFIG_SERIAL_OF_PLATFORM
CONFIG_TMPFS
CONFIG_TMPFS_POSIX_ACL
```

Edit config and open configurations:      

```
cd ~/virtio_media_playground/linux
nano drivers/media/Kconfig
第二步：找到第 233 行附近的 MEDIA_VIRTIO
找到类似下面的内容（第 233 行附近）：

Code snippet


config MEDIA_VIRTIO
	tristate "Virtio-media Driver"
	depends on MEDIA_SUPPORT && VIRTIO && VIDEO_DEV && 64BIT && (X86 || ARM && CPU_LITTLE_ENDIAN)
第三步：把 ARM 改为 ARM64（或者加上 ARM64）
修改为：

Code snippet


config MEDIA_VIRTIO
	tristate "Virtio-media Driver"
	depends on MEDIA_SUPPORT && VIRTIO && VIDEO_DEV && 64BIT && (X86 || ARM || ARM64)
保存并退出（nano 中按 Ctrl + O 保存，Ctrl + X 退出）
```
Rebuild the kernel, then you could use:
