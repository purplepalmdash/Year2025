# 20260827
### 1. mpv issue

```
# 授予媒体读取权限（最重要）
adb shell pm grant is.xyz.mpv android.permission.READ_MEDIA_VIDEO
adb shell pm grant is.xyz.mpv android.permission.READ_MEDIA_IMAGES
adb shell pm grant is.xyz.mpv android.permission.READ_MEDIA_AUDIO

# 兼容旧权限
adb shell pm grant is.xyz.mpv android.permission.READ_EXTERNAL_STORAGE
adb shell pm grant is.xyz.mpv android.permission.WRITE_EXTERNAL_STORAGE

# 尝试授予所有文件访问权限（部分设备有效）
adb shell appops set is.xyz.mpv MANAGE_EXTERNAL_STORAGE allow
adb shell appops set is.xyz.mpv READ_EXTERNAL_STORAGE allow
adb shell appops set is.xyz.mpv READ_MEDIA_VIDEO allow
```
