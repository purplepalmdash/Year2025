### 2. ika(debian 13)
Enable backport repository:      

```
test@d3000debian:~$ cat /etc/apt/sources.list | grep backport
# backports 软件源，请按需启用
 deb http://mirrors.nju.edu.cn/debian trixie-backports main contrib non-free non-free-firmware
# deb-src http://mirrors.nju.edu.cn/debian trixie-backports main contrib non-free non-free-firmware
```
Install libgbm1 and mesa-vulkan-drivers:        

```
 sudo apt install -t trixie-backports mesa-vulkan-drivers libgbm1
```
Install ika packages:      

```
 sudo apt install ./ika-base_260726-1_arm64.deb ./ika-lineageos_260726-1_arm64.deb
```
