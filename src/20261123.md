### 2. ninfer-all(V100)
Download the dep files via:     

```
curl -fLO https://distfiles.gentoo.org/distfiles/62/ffmpeg-9.0.2.tar.xz
curl -fLO https://distfiles.gentoo.org/distfiles/8b/dav1d-1.5.4.tar.xz

```
Build via:    

```
# ls third_party/media-sources/
dav1d-1.5.4.tar.xz  ffmpeg-9.0.2.tar.xz
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_CUDA_COMPILER=/usr/local/cuda-12.8/bin/nvcc  -DCMAKE_CUDA_ARCHITECTURES=70
cmake --build build --target ninfer-serve ninfer-calibrate
```

### 3. ninfer-all(a6000)

