### 2. pip dep issue
issue and solution, displayed in following:       

```
ComfyUI 0.43.0 的 requirements.txt 里写了：

comfyui-workflow-templates==0.11.97
这个元包会再依赖：

comfyui-workflow-templates-media-assets-02==0.1.24
而你现在用的国内镜像（清华等）还没有同步到这个精确版本，或者短暂缺失，所以 pip 报：

No matching distribution found for comfyui-workflow-templates-media-assets-02==0.1.24

临时切官方源装 templates（最简单）
bash
cd /media/big/transHead/ComfyUI-0.43.0
source venv/bin/activate

# 先单独装 workflow-templates 相关（强制用官方源）
pip install comfyui-workflow-templates==0.11.97 \
  -i https://pypi.org/simple \
  --trusted-host pypi.org \
  --trusted-host files.pythonhosted.org

# 再装其余依赖（继续用国内源）
pip install -r requirements.txt
```
