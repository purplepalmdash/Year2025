### 1. pi/nvm
Install nvm:     

```
sudo apt update && sudo apt install -y curl
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.4/install.sh | bash
source ~/.bashrc
nvm --version
0.40.4
```
Install/configure:     

```
export NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node
# better add this into your .bashrc
nvm install 22
nvm use 22
```
Then install pi via:    

```
curl ..........
npm config set registry https://registry.npmmirror.com
 npm install -g @jmfederico/pi-web --allow-scripts=node-pty --registry=https://registry.npmmirror.com
pi-web install
```
