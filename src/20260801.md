### 1. archlinux mkpkg
Step:    

```
sudo pacman -S devtools
pkgctl repo clone --protocol https qemu

# Automatically install dependencies and build the pkg, then install
makepkg -si
# only build the pkg
makepkg -s
```
Make changes to source code, then :     

```
makepkg -s -e --skippgpcheck
```

```

### 2. gpg error
when building qemu on archlinux, met the  error:    

```
==> Verifying source file signatures with gpg...
    qemu-11.0.3.tar.xz ... FAILED (unknown public key 3353C9CEF108B584)
==> ERROR: One or more PGP signatures could not be verified! 
unknown public key 3353C9CEF108B584
```
solved via:    

```
gpg --recv-keys 3353C9CEF108B584

```
### 3. change pkg version
Change the items in PKGBUILD:    

```
pkgver=11.0.3
pkgrel=1.1   # 或者 pkgrel=2
```

then build with:     

```
# 1. 带 -e 增量打包（不会重新解压/不会覆盖你之前改好的 C 代码）
makepkg -s -e -f --skippgpcheck

# 2. 将生成的新版本包安装覆盖到系统
sudo pacman -U qemu-*-11.0.3-1.1-x86_64.pkg.tar.zst
```
### 4. examine the build log
When building qemu, examine the meson buld log via:    

```
grep -rn "Enabling virglrenderer unstable APIs" src/qemu-11.0.3/build/
