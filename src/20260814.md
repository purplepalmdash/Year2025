### 3. moonlight/sunshine
Step:      

```
sudo apt install ./sunshine-debian-trixie-arm64.deb
sudo usermod -aG input $USER
sudo usermod -aG video $USER
sudo usermod -aG render $USER
echo 'KERNEL=="uinput", SUBSYSTEM=="misc", OPTIONS+="static_node=uinput", TAG+="uaccess", MODE="0660", GROUP="input"' | sudo tee /etc/udev/rules.d/85-sunshine-input.rules
sudo modprobe uinput
sudo udevadm control --reload-rules && sudo udevadm trigger
sunshine --creds sunshine MyPassword123
sunshine
```
Then:      

```
ssh -L 47990:localhost:47990 test@<Debian设备的IP>
https://localhost:47990
Configure the login
```
Configure the auto-start:       

```
mkdir -p ~/.config/systemd/user/
nano ~/.config/systemd/user/sunshine.service

[Unit]
Description=Sunshine server for Moonlight
After=network-online.target
Wants=network-online.target

[Service]
ExecStart=/usr/bin/sunshine
Restart=on-failure
RestartSec=5

[Install]
WantedBy=default.target

systemctl --user daemon-reload
systemctl --user enable --now sunshine
systemctl --user status sunshine

loginctl enable-linger $USER
```
